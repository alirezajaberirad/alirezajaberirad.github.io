# Alireza Jaberi Rad Portfolio - Codex Redesign

This is a separate redesign copy of the original `portfolio` draft. The original folder was left untouched.

## Run Locally

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview the Built Site

```bash
npm run serve:dist
```

The May 2026 CV is included in `public/Alireza_Jaberi_Rad_CV_May_2026.pdf` so the CV links work in the built site.
